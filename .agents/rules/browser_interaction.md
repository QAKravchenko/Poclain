# Правило работы с браузером (Browser Interaction Rule)

## 1. Режим работы AI-ассистента (агента)
- При исследовании структуры сайта, поиске локаторов, анализе DOM и отладке агент открывает и использует браузер **исключительно в скрытом фоновом режиме (`headless: true`)**.
- Агент не должен выводить графические окна браузера на рабочий стол пользователя во время написания кода и поиска локаторов, чтобы не создавать визуальных помех.

## 2. Режим прогона тестов (для пользователя)
- В файле конфигурации `playwright.config.ts` для локального запуска тестов включен **видимый режим браузера (`headless: false`)** с флагом `--start-maximized`.
- Когда пользователь запускает тесты (через расширение VS Code Playwright или из терминала), окно браузера распахивается на весь экран монитора, позволяя наглядно наблюдать за ходом выполнения тестов и кликами.
